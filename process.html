Our Process

This page documents the steps our team took to research, plan, and build this website.

Step 1: Research the Innovator

We researched Mark Dean's life, career, and inventions. This assignment asked us to find information about a technology innovator and document their contributions to the field.

View assignment

Step 2: Create a Wireframe

Before building the site we planned each page using a wireframe. This showed where the navigation, images, and text would go on each page before we wrote any code.

View assignment

Step 3: Build the Website

We built the website using HTML, CSS, and Bootstrap. Each team member contributed to different pages and we used GitHub to store and publish the finished site.

View assignment

Step 4: Collect Feedback

Each team member interviewed someone outside the group and asked them to navigate the site and give feedback. We then used those suggestions to improve the design and content.

View assignment

Step 5: Data Visualization

We created a data visualization to present information about Mark Dean and his contributions in a visual format.
